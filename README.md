# KavyaVerse Invitations

Create a premium, elegant digital invitation service website for a brand called:

KAVYAVERSE DIGITAL

Tagline: “Every Design, Every Occasion.”

The uploaded logo is the primary brand reference. Build the entire visual identity around the logo’s existing aesthetic:

- Warm ivory / textured cream background

- Antique gold

- Rich brown

- Deep wine / maroon accents

- Dark charcoal typography

- Elegant Indian-inspired decorative flourishes

- Premium wedding-card feeling without looking old-fashioned

- Sophisticated, warm, celebratory and trustworthy

IMPORTANT:

This is NOT just a portfolio website.

It is a DIGITAL INVITATION SHOP where users should immediately understand:

1. What services are available

2. What type of invitation they need

3. How much it costs

4. What they receive

5. How to order

The website should feel extremely easy for an Indian customer to understand within 5–10 seconds.

DESIGN DIRECTION

Overall visual style:

Premium Indian editorial design + modern digital commerce.

Do NOT make it look like:

- a generic wedding website

- a cheap invitation template website

- an overly colourful Indian wedding website

- a corporate SaaS website

Use:

- ivory textured background

- antique gold borders

- dark maroon accents

- elegant serif headings

- clean modern sans-serif body text

- subtle ornamental curves

- lots of whitespace

- premium invitation mockups

- soft shadows

- thin gold dividers

- rounded cards only where appropriate

Typography should combine:

Elegant high-contrast serif for major headings

+

Clean modern sans-serif for prices, descriptions and navigation.

Use the uploaded KavyaVerse Digital logo as the main visual identity reference.

--------------------------------------------------

UX PRINCIPLE

The website must answer these questions immediately:

“What can I order?”

“How much does it cost?”

“What will I receive?”

“Can I customise it?”

“How quickly can I get it?”

“How do I order?”

Avoid long paragraphs.

Use:

large headings,

short descriptions,

clear prices,

visual examples,

simple CTAs,

and strong information hierarchy.

The experience should feel like:

DISCOVER → CHOOSE → SEE PRICE → UNDERSTAND → ORDER

Make the website mobile-first because most customers will discover and share invitations through WhatsApp.
