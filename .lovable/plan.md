# KavyaVerse Digital UI Redesign

## Goal
Rework the existing invitation shop into a fast, price-first experience with a modern Indian editorial identity based on the uploaded logo.

## What will change
- Simplify the header for desktop and mobile, with the primary ordering action always visible.
- Replace artwork-led hero imagery with a structured invitation-preview composition made from interface elements and subtle ornaments.
- Convert occasions into a compact horizontal selector for rapid browsing.
- Refocus format cards, pricing, and design cards so the item, inclusions, and price are visible immediately.
- Rebuild the design gallery previews as elegant placeholders rather than invitation artwork, while retaining working filters.
- Tighten the included-items grid, ordering steps, celebration collections, trust points, final action, and footer to match the supplied wording.
- Preserve the current ivory, gold, maroon, brown, and charcoal token system while reducing decorative excess.

## Responsive behavior
- Desktop: editorial split hero, four-column design grid, horizontal process.
- Tablet: three-column design grid.
- Mobile: two-column design grid, scrollable category/filter rows, compact header with menu and primary action.

## Validation
- Verify the page renders and the menu, filters, and WhatsApp actions work.
- Check desktop and mobile layouts for clipping, overlap, and readable prices.
